# Project workflow

Before writing code, read `memory-bank/CONTEXT.md` and `memory-bank/AGENTS.md`.
After every change, add a newest-first entry to `memory-bank/CHANGELOG.md` and
update `memory-bank/CONTEXT.md` to reflect the current implementation and deployment.
This includes code, database migrations, tests, configuration, and deployments.
Never record credentials or other secrets in these files.
